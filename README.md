# ARENA 82 — Interstate Survivors

**Jouer : <https://elzuzu.github.io/arena82-play/>**

Survivor-like en voxels et en voiture : Megabonk rencontre Interstate '76. Tu conduis une
voiture disco armée de gatlings et d'une boule à facettes, tu écrases la horde, tu ramasses les
gemmes et tu choisis tes améliorations. Chaque monde est généré procéduralement à partir d'une graine.

Ce dépôt ne contient que le jeu compilé (`index.html`, un fichier autonome). Il est mis à jour
automatiquement depuis le dépôt source.

## Commandes

| Action | Clavier | Manette |
|---|---|---|
| Conduire | WASD / flèches (ZQSD sur AZERTY) | stick gauche + gâchettes |
| Saut (encore en l'air avec DOUBLE HOP) | Espace, appui bref | A |
| Frein à main, dérapage | Espace maintenue, ou C | B |
| Nitro | Maj | RB |
| SLAM : en l'air, piqué au sol ; au sol, gros saut hydraulique. Onde de choc à l'impact | E ou clic droit | Y / LB |
| DISCO INFERNO | F | X |
| Choisir une carte / relancer | 1 2 3 / R | clic |
| Pause | Échap | Start |

Sur téléphone ou tablette, des boutons tactiles apparaissent pendant la partie.
